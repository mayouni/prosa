The commands of Prosa

A command of Prosa is one verb of the prosa program: check, measure, brief, drift, readings, conformance, pack and version. The commands let a user, a person or an AI agent, judge a text, take a profile from approved pages and hand a writing contract to an AI agent.

The syntax of the eight verbs

The program prints its own syntax when it runs with no argument. The reference court runs under Node as node tools/prosa/cli.js, and this page writes it prosa.

$ prosaprosa 0.1.0 (language 0.1)  prosa check <path>... [--level N] [--style S --form F --subject T --lang L] [--proz F]... [--json] [--quiet]  prosa measure <path>... [--as NAME] [--json]  prosa brief <file.proz> [--piece P | --style S [--form F] [--lang L]]  prosa drift <drafts>... --against <corpus> [--lang L] [--json]  prosa readings <path>...  prosa conformance [dir]  prosa pack <file.proz> [-o out.json]      prosa pack --check  prosa versionExit codes: 0 no error (warnings allowed), 1 an error, 2 a usage or read error.

prosa check judges a declaration and its texts

The verb check takes .proz files, texts or folders. It judges each declaration, then each text a PIECE names, and prints one finding per refusal with a closing count. The option --level N stops the court at a stage, and --json prints the findings as data.

$ prosa check conformance/fixtures/term-synonym.prozconformance/fixtures/term-synonym.md:3  error  TERM_SYNONYM  programmer    "developer" stands for the person who writes programs: the house word is "programmer".    Rule programmer · The author, 2026-11-26: a ruling written for this fixture1 error(s), 0 warning(s) across 2 file(s) at level 4
$ prosa check conformance/fixtures/term-synonym-lawful.proz0 error(s), 0 warning(s) across 2 file(s) at level 4

A text with no declared piece is judged with --style, --form, --subject and --lang, and --proz names the file that declares the style.

prosa measure takes a profile from approved pages

The verb measure reads a corpus as one pool and writes its measures as a PROFILE declaration. The author adjusts the bounds and rules on them, and the profile enters the style with the corpus as its evidence.

$ prosa measure conformance/fixtures/on-profile-lawful.md// Measured by prosa measure on 1 page(s), 121 prose words, 25 sentences.// median 3 (quartiles 2 and 4) | over 40 words 4 % | under 10 words 96 %// per thousand words: colons 0, dashes 0, exclamations 0, questions 0// paragraphs of one sentence 0 %DEFINE PROFILE measured_voice (  SENTENCE_MEDIAN 3 WITHIN 1,  SENTENCES_OVER 40 AT_MOST 8 PER_HUNDRED,  SENTENCES_UNDER 10 AT_LEAST 48 PER_HUNDRED,  DASHES AT_MOST 1 PER_THOUSAND,  COLONS AT_LEAST 1 PER_THOUSAND,  EXCLAMATIONS AT_MOST 1 PER_THOUSAND,  MIN_WORDS 300,  EVIDENCE "Measured on conformance/fixtures/on-profile-lawful.md: 121 words")

prosa brief writes the contract of an AI agent

The verb brief turns a declared piece or style into the contract an AI agent receives before it drafts: the form, the terms, the written forms and the measure of the voice. The contract states what to write, which is the form of instruction AI models follow best.

$ prosa brief conformance/fixtures/term-synonym.proz --piece the_page# The writing contract of the piece the_pageThis contract states the declared style house for a text in language `en`. The Prosa court judges the text against it after every write.## One thing, one word- Write "programmer" for the person who writes programs (in place of: developer, developers).## The loopDraft, run `prosa check <file> --json`, and repair each finding by its code until the court is silent. A finding names the rule, the written form and the ruling it comes from.

prosa drift compares drafts with the pages of the author

The verb drift measures a set of drafts against a corpus and lists what the drafts over-use. Each line is a candidate: it becomes a rule when the author rules on it.

$ prosa drift conformance/fixtures/off-profile.md --against conformance/fixtures/on-profile-lawful.md// prosa drift: 118 draft words against 121 corpus words.// Each candidate is a measure, offered to the author's ruling. A candidate becomes a rule when the author rules on it.// measure            drafts   corpus// DASHES               42.4        0   per thousand words// COLONS                  0        0   per thousand words// EXCLAMATIONS            0        0   per thousand words// QUESTIONS               0        0   per thousand words// SENTENCE_MEDIAN        16        3   words

prosa readings lists the judgments of level 5

The verb readings lists each declared reading of each piece as recorded or due, with its question and the path of its record. It always exits with 0: a reading is a record, and the verdict belongs to the court.

prosa conformance runs every fixture and its lawful twin

The verb conformance runs the suite of the standard. Each refused fixture names the code it expects on its first line, and its lawful twin expects silence.

$ prosa conformance66 of 66 fixtures pass

prosa pack and prosa version state what a court runs

The verb pack compiles a .proz file and every file it uses into one JSON pack: the declarations as data, with the SHA-256 sum of each source. The form prosa pack --check compares the versions of the court with the manifest of the protocol. The verb version prints the three versions a verdict depends on.

$ prosa versionprosa 0.1.0 (language 0.1, contract 0.1)

The exit codes a script reads

Every verb that judges exits with 0 when no error stands, with 1 on an error and with 2 on a usage or read error. A warning leaves the exit code at 0, so a build fails on errors alone.
