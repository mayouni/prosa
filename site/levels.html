The five levels of judgment

A level of Prosa is one of the five stages at which the court judges, in a fixed order: syntax, declaration, text, measure and reading. The order ensures that a text is judged only against a lawful declaration: an error at one stage stops the next.

What each stage judges and what it needs

LevelWhat is judgedThe court needs
1 SyntaxThe .proz file parses and each field has its shapeThe file
2 DeclarationThe style and the piece are lawful by themselvesEvery file reached through USE
3 TextWords, terms, patterns and positionsThe text of each piece
4 MeasureThe profile, and the budget of a word list, over a whole pieceThe text of each piece
5 ReadingA declared question, listed as recorded or dueThe folder of records

The option --level N stops the court at the stage asked. Levels 1 to 4 use no AI model and no language toolkit: the same text gives the same verdict on every machine.

Level 1: a field that stands twice

The court reads the file as USE lines and DEFINE declarations and checks the shape of each field.

// Expected: DUPLICATE_FIELD
DEFINE STYLE house (
  LANGUAGES [en],
  LANGUAGES [fr]
)

Level 2: a pattern that fails its own example

The court judges the declaration by itself: every reference names a declaration of the right kind, every rule cites its evidence, and every pattern passes its own examples. The pattern below accepts the sentence it declares as refused, so the court refuses the pattern before it reaches a text.

// Expected: EXAMPLE_NOT_REFUSED
DEFINE PATTERN lack_listed (
  MATCHES ["not yet", "never" WITHIN 3 "run"],
  CODE LACK_LISTED,
  REFUSED "The verifier checks the declaration.",
  WRITTEN "The verifier checks the declaration.",
  EVIDENCE "The author, 2026-11-26: a ruling written for this fixture"
)
$ prosa check conformance/fixtures/example-not-refused.proz
conformance/fixtures/example-not-refused.proz:5  error  EXAMPLE_NOT_REFUSED  lack_listed
    The REFUSED example is not refused by its own pattern: "The verifier checks the declaration.".

1 error(s), 0 warning(s) across 1 file(s) at level 4

Level 3: a statement made twice in the first 150 words

The court reads the text zone by zone and judges words, terms, patterns and positions. The form below asks that a statement stand once per screen, and the text repeats two content words in a row.

// Expected: SAY_ONCE
DEFINE STYLE house (
  HOLDS []
)
DEFINE FORM page (
  SAY_ONCE FIRST 150,
  EVIDENCE "The author, 2026-11-26: a ruling written for this fixture"
)
DEFINE PIECE the_page (
  FILE "say-once.md",
  FOLLOWS house,
  FORM page,
  SUBJECT "court"
)
# The court of Prosa

Level 4: three measures outside the profile

The court measures the whole piece and compares each measure with its bound. A finding of this stage stands on line 1 and names the measure, its value and the bound the profile asks.

DEFINE PROFILE voice (
  SENTENCES_OVER 40 AT_MOST 10 PER_HUNDRED,
  DASHES AT_MOST 4 PER_THOUSAND,
  SENTENCE_MEDIAN 6 WITHIN 4,
  MIN_WORDS 50,
  EVIDENCE "The author, 2026-11-26: a ruling written for this fixture"
)

Level 5: a reading listed as recorded or due

A READING puts a question to a reader, a person or an AI model. The record of a reading is a Markdown file in the declared folder, named after the text and the reading. The court lists each reading as recorded or due: a reading carries no code and leaves the exit code unchanged.

The three exit codes of the court

  • The court exits with 0 when no error stands: warnings are allowed.
  • The court exits with 1 when an error stands.
  • The court exits with 2 on a usage error or a file it fails to read.
