The text model of Prosa

The text model of Prosa is the set of definitions that turn a Markdown or HTML file into blocks, zones, sentences, words and measures. It ensures that two implementations of the court give the same findings, byte for byte.

The blocks the court reads, and the blocks it skips

The court cuts a Markdown file into paragraphs at blank lines and gives each one a kind.

  • A prose block is a paragraph, a list item or a quotation: the rules judge it.
  • A code block is a fence or an indented paragraph: the rules skip it.
  • A skipped block is a heading line, a table, a comment, an image or a caption: the heading is kept and the rest is left.

The front matter at the top of a file gives the title, the subject, the language and the status of the text. An HTML file gives the same blocks: h1 to h6 are headings, p and blockquote are prose, li and the cells of a table are list items, and pre is code. The court leaves the content of script, style, code, template and nav unread.

The six zones a rule reads

Each block stands in one zone, and a rule names the zones it reads with the field IN.

ZoneWhat stands in it
titleThe first heading of level 1, or the title of the front matter
headingEvery other heading
ledeThe first prose block of the text
bodyEvery other paragraph
listA list item
quoteA quotation

A rule reads the lede, the body, the lists and the quotations by default. A declared ZONE adds a region of its own, opened and closed by two comments in the text.

How a word and a sentence are bounded

A word is a run of letters and digits, which may hold an apostrophe or a hyphen between two such runs: decision-maker is one word. Matching compares words in lower case, and inline code is blanked before a rule reads a block: a name in code is outside the prose.

A sentence ends at a space that follows a full stop, an exclamation mark, a question mark or an ellipsis and precedes a capital letter or an opening mark. The length of a sentence is its count of runs of characters between spaces.

The eleven measures of a profile

The measures read the prose blocks only. Their definitions are those of the style lint of the first house, so a profile measured by one program is judged by the other.

MeasureDefinition
SENTENCE_MEDIANThe sentence lengths in order; the value at the middle index
SENTENCES_OVER NSentences longer than N words, outside list items
SENTENCES_UNDER NSentences shorter than N words
DASHESThe count of long dashes and of hyphens set between two spaces
COLONS, QUESTIONSThe count of colons and of question marks
EXCLAMATIONSThe count of exclamation marks
COLD_EXCLAMATIONSThe exclamation marks of a block that follows no run of code and names no result
ELLIPSESProse blocks that end on an ellipsis
COLON_LEADSProse blocks that end on a colon and are followed by a prose block
ONE_SENTENCE_PARAGRAPHSProse blocks of one sentence and more than three words

A rate per thousand is the count times 1000 over the prose words, rounded to one decimal. A corpus is measured as one pool: every sentence of every page enters one median.

A profile taken from a page by the court

The command prosa measure applies these definitions to approved pages and writes the result as a PROFILE declaration, with the corpus as its evidence.

$ prosa measure conformance/fixtures/on-profile-lawful.md// Measured by prosa measure on 1 page(s), 121 prose words, 25 sentences.// median 3 (quartiles 2 and 4) | over 40 words 4 % | under 10 words 96 %// per thousand words: colons 0, dashes 0, exclamations 0, questions 0// paragraphs of one sentence 0 %DEFINE PROFILE measured_voice (  SENTENCE_MEDIAN 3 WITHIN 1,  SENTENCES_OVER 40 AT_MOST 8 PER_HUNDRED,  SENTENCES_UNDER 10 AT_LEAST 48 PER_HUNDRED,  DASHES AT_MOST 1 PER_THOUSAND,  COLONS AT_LEAST 1 PER_THOUSAND,  EXCLAMATIONS AT_MOST 1 PER_THOUSAND,  MIN_WORDS 300,  EVIDENCE "Measured on conformance/fixtures/on-profile-lawful.md: 121 words")
